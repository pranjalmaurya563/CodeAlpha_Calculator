
# Calc. | Smart Calculator

A modern, responsive calculator built using HTML, CSS, and JavaScript. It features a clean dark interface, arithmetic operations, keyboard support, calculation history, and light/dark themes.

## Features

- Basic arithmetic: Addition, subtraction, multiplication, and division
- Decimal calculations and negative numbers
- Real-time result preview
- Clear and delete functionality
- Percentage and sign-change operations
- Keyboard support
- Calculation history with reusable results
- Copy result to clipboard
- Light and dark theme toggle
- Persistent calculation history and theme preference using localStorage
- Responsive interface for different screen sizes
- Safe expression parser without using eval()

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage API
- Clipboard API

## Getting Started

1. Clone this repository:

   git clone (https://github.com/pranjalmaurya563/CodeAlpha_Calculator.git)

2. Open the project folder in VS Code.
3. Open index.html using Live Server or your browser.

No additional JavaScript packages are required.

## How to Use

1. Enter numbers using the calculator buttons or keyboard.
2. Select an arithmetic operator.
3. Press the equals button or Enter to calculate.
4. Use AC to clear and DEL to delete the last character.
5. Open History to view previous calculations.
6. Use Copy Result to copy the displayed result.
7. Toggle between light and dark themes.

## Data Storage

Calculation history and theme preference are stored locally in the browser using localStorage. The data is not automatically synchronized across devices.
